# InfoNCE K=1 + Post-hoc GRU

Five commands, run from the repository root. The GRU training paths are generated by the K=1 checkpoint; inference disables GRU beam guidance, so GRU only reranks completed beam candidates.

1. Train InfoNCE MIND K=1 (10 epochs):

```bash
.venv/bin/python src/medmigcr_mind/train_mind_infonce_ddxplus.py \
  --train_csv data/processed/ddxplus_v2/train_queries.csv \
  --valid_csv data/processed/ddxplus_v2/valid_queries.csv \
  --graph_dir data/processed/primekg_graph \
  --out_dir experiments/ablations/infonce_k1_gru_posthoc/checkpoints/mind_k1 \
  --K 1 --epochs 10 --batch_size 128 --lr 1e-3 --weight_decay 1e-5 \
  --seed 42 --device cpu
```

2. Generate K=1 paths for GRU training (first 100k training queries):

```bash
.venv/bin/python scripts/reranking/build_gru_path_reranker_dataset.py \
  --queries_csv data/processed/ddxplus_v2/train_queries.csv \
  --graph_dir data/processed/primekg_graph \
  --checkpoint experiments/ablations/infonce_k1_gru_posthoc/checkpoints/mind_k1/clinical_mind_infonce_k1.pt \
  --condition_map data/mappings/ddxplus_v2/condition_to_primekg.json \
  --output_jsonl experiments/ablations/infonce_k1_gru_posthoc/data/k1_train_paths_100k.jsonl \
  --limit_patients 100000 --interest_count 1 \
  --max_hops 10 --beam_width 128 --paths_per_interest 4096 \
  --alpha 1.0 --beta 0.1 --device cpu --graph_device auto
```

3. Train the GRU reranker:

```bash
.venv/bin/python scripts/reranking/train_gru_path_reranker.py \
  --train_jsonl experiments/ablations/infonce_k1_gru_posthoc/data/k1_train_paths_100k.jsonl \
  --metadata_json experiments/ablations/infonce_k1_gru_posthoc/data/k1_train_paths_100k.metadata.json \
  --graph_dir data/processed/primekg_graph \
  --out_checkpoint experiments/ablations/infonce_k1_gru_posthoc/checkpoints/gru_k1.pt \
  --epochs 10 --steps_per_epoch 2000 --batch_size 256 \
  --hard_negative_top_k 32 --lr 1e-3 --weight_decay 1e-5 \
  --seed 13 --device cpu
```

4. Run K=1 retrieval with post-hoc GRU on 5,000 test queries:

```bash
.venv/bin/python scripts/retrieval/run_ddxplus_infonce_gru_rerank.py \
  --test_queries_csv data/processed/ddxplus_v2/test_queries.csv \
  --graph_dir data/processed/primekg_graph \
  --mind_checkpoint experiments/ablations/infonce_k1_gru_posthoc/checkpoints/mind_k1/clinical_mind_infonce_k1.pt \
  --reranker_checkpoint experiments/ablations/infonce_k1_gru_posthoc/checkpoints/gru_k1.pt \
  --condition_map data/mappings/ddxplus_v2/condition_to_primekg.json \
  --output_csv experiments/ablations/infonce_k1_gru_posthoc/results/test5000/predictions.csv \
  --summary_json experiments/ablations/infonce_k1_gru_posthoc/results/test5000/retrieval_summary.json \
  --interest_count 1 --max_hops 10 --beam_width 128 --paths_per_interest 4096 \
  --limit_patients 5000 --disable_gru_beam_guidance --device cpu --graph_device auto
```

5. Calculate metrics:

```bash
.venv/bin/python scripts/evaluation/evaluate_ddxplus_retrieval.py \
  --queries_csv data/processed/ddxplus_v2/test_queries.csv \
  --condition_map data/mappings/ddxplus_v2/condition_to_primekg.json \
  --predictions experiments/ablations/infonce_k1_gru_posthoc/results/test5000/predictions.csv \
  --output_dir experiments/ablations/infonce_k1_gru_posthoc/results/test5000/evaluation \
  --target_mode pathology --topk 1 5 10 20 50 --limit_patients 5000
```
